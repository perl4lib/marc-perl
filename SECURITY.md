# Security policy

## Supported versions

Security fixes are made to the latest release of each distribution in this
repository (`MARC-Record`, `MARC-Lint`, `MARC-File-XML`, `MARC-File-MiJ`,
`MARC-File-MARCMaker` and `MARC-Charset`).

## Reporting a vulnerability

Please do **not** open a public issue for a suspected vulnerability.

Report it privately using GitHub's
["Report a vulnerability"](https://github.com/perl4lib/marc-perl/security/advisories/new)
form (under the repository's *Security* tab), including:

* the affected distribution and version,
* a description of the problem and its impact, and
* if possible, a minimal reproduction, such as a small input file or script.

If that is not available to you, contact the maintainer at the address given
in the `AUTHOR` metadata of the affected distribution.

You can expect an acknowledgement of your report, and we will keep you
informed as it is investigated and a fix is prepared. Once a fix is released
we are happy to credit you in the release notes unless you prefer otherwise.
