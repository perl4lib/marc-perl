=head1 NAME

MARC-XML

=head1 DESCRIPTION

MARC-XML is an extension to the MARC-Record distribution for working with
XML data encoded using the MARC21slim XML schema from the Library of Congress.

For more details see L<http://www.loc.gov/standards/marcxml/>.

=head1 INSTALLATION

To install this module type the following:

    perl Makefile.PL
    make
    make test
    make install

=head1 DEPENDENCIES

This module requires these other modules and libraries:

=over 4

=item * MARC::Record

=item * MARC::Charset

=item * XML::LibXML

=back
